Gizlilik bilgilendirmesi

Kısa özet

Bu sitede üyelik, iletişim formu, reklam, analiz aracı veya pazarlama çerezi yoktur. Masaüstü uygulamasının program, ayar ve günlük verileri siteye gönderilmez.

1. Site ziyareti

Proje sahibi ziyaretçi analizi yapmaz, reklam ağı kullanmaz ve tarayıcınıza çerez veya yerel depolama kaydı bırakmaz. Site GitHub Pages üzerinde barındırılır. IP adresi, tarih-saat, tarayıcı bilgisi ve istenen adres gibi teknik bağlantı kayıtları GitHub tarafından hizmetin sunulması ve güvenliğinin sağlanması amacıyla işlenebilir.

2. Masaüstü uygulaması

Okul Zili çevrimdışı çalışır. Okul adı, zil programı, tatil takvimi, ses dosyası yolları, profil bilgileri ve teknik olay günlükleri kullandığınız bilgisayarda saklanır. Program bu verileri geliştiriciye, bu siteye veya başka bir bulut hizmetine otomatik olarak göndermez.

3. E-posta ve GitHub iletişimi

E-posta gönderir veya GitHub üzerinde kayıt açarsanız ilgili hizmetlere sunduğunuz ad, hesap bilgisi ve ileti içeriği talebin incelenmesi için işlenir. GitHub Issues herkese açık olabilir.

Kurum verisi paylaşmayın

Okul adı, gerçek zil çizelgesi, kurum içi anons, kullanıcı PIN'i, günlük, yedek, ekran görüntüsü veya ses dosyası göndermeyin. Sorunu örnek ve anonim bilgilerle açıklayın.

4. Uygulama yedekleri ve günlükleri

Yedek ve teknik günlük dosyaları kurumunuzun çalışma düzenine ilişkin bilgi içerebilir. Bunları yalnızca kurumunuzun onayladığı güvenli ortamlarda saklayın; herkese açık GitHub kayıtlarına yüklemeyin.

5. İletişim

Gizlilikle ilgili sorularınızı aalidemirci@gmail.com adresine iletebilirsiniz. E-postanıza gerçek kurum verisi veya dosya eklemeyin.

GitHub hizmetleri için GitHub Gizlilik Bildirimi geçerlidir. Sitenin barındırma veya veri işleme yapısı değişirse bu metin yayımdan önce güncellenir.
