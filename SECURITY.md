# Güvenlik Politikası

Okul Zili için güvenlik açığı bildirimlerini herkese açık GitHub Issues yerine `aalidemirci@gmail.com` adresine gönderin.

Bildirimde gerçek okul adı, kurum içi zil çizelgesi, kullanıcı PIN'i, günlük, yedek, ses/anons dosyası veya ekran görüntüsü paylaşmayın. Sorunu kişisel ve kurumsal veri içermeyen yeniden üretim adımlarıyla açıklayın.

Desteklenen sürüm en son yayımlanan kararlı sürümdür. Güvenlik düzeltmeleri doğrulandıktan sonra yeni bir GitHub Release olarak yayımlanır.
